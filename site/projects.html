Capsule Closet

2024 – 2025
Team of four · technical lead

A full-stack web app and mobile concept that catalogs a user’s wardrobe and generates daily outfit suggestions. Google Gemini identifies and tags clothing from photographs; OpenAI’s models assemble outfits against the user’s preferences, calendar events, and local weather; Imagen renders a preview of the result. It also lets friends lend and borrow pieces from each other — the point being to reduce what people buy and throw away. Built over four months and roughly 100 hours in the Code2College AI program, then carried into my entrepreneurship course, where we gathered over 100 survey responses on pricing and prototype feedback before deciding how to develop it further.

  • OpenAI API
  • Google Gemini
  • Imagen
  • JavaScript
  • Python
  • Full-stack
People’s Favorite AI Project Award, 2025

DevTools vehicle simulation

2024 – 2026
Polaris Inc. · Software Engineering Intern

Internal tooling that lets Polaris developers test infotainment software against a mock vehicle rather than a physical one, which removes a real bottleneck: there are far more engineers than there are vehicles to borrow. My work went into the D-Bus layer that publishes simulated vehicle signals so the infotainment stack behaves as if a real machine were attached, written in C++, QML, JavaScript, and CSHTML. I also helped start a multi-year effort using a rules engine to make data collection, storage, and transformation cheaper across the organization.

  • C++
  • QML
  • D-Bus
  • JavaScript
  • InRule
  • Linux

Hardware memory game

Sep 2025
Cirrus Logic hackathon · led a team of five

A physical Simon-style memory game built in a single hackathon. A Raspberry Pi 4 drives a 4×4 grid of illuminated buttons and a speaker, generating sequences that get longer as the player survives them, with audio feedback on each press. Python throughout, reading button state and driving the LEDs over GPIO. My job was as much decomposition as code: splitting the build into independent pieces the five of us could work on in parallel without blocking each other.

  • Python
  • Raspberry Pi 4
  • GPIO
  • Audio I/O

Workout form tracker

Mar 2025
RRISD hackathon · led a team of four

A browser application that watches a user exercise through their webcam and tells them, in real time, when their form has broken down. Built on Google Teachable Machine with a model trained on correct and incorrect repetitions. Nine hours from empty repository to working prototype and pitch, which placed third against more than thirty teams.

  • Teachable Machine
  • JavaScript
  • Computer vision
  • HTML / CSS
3rd place of 30+ teams
